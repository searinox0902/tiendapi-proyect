## FAQs

Resuelve tus dudas sobre nuestro proveedor de facturación electrónica

### ¿Qué es Alanube?

Alanube es un Backend as a Service (BaaS) de facturación electrónica: una API REST para integrar tu ERP/POS/software contable al flujo de facturación en Colombia (DIAN). En lugar de facturar en una plataforma, tu sistema envía los documentos y recibe estados automáticamente vía API.

### ¿Qué es una API de facturación electrónica y para qué sirve?

Una API de facturación electrónica es una interfaz que permite que tu software genere documentos electrónicos desde tu propio flujo (checkout, ERP, POS) y los procese según el marco de la DIAN, facilitando el envío y la validación.

### ¿Cuáles son los beneficios de trabajar con Alanube?

Con Alanube logras la automatización de los procesos de facturación, cumplimiento con las normativas fiscales, integración sencilla con otros sistemas, reducción de errores manuales y la optimización del tiempo administrativo.

### ¿Qué tipo de comprobantes fiscales electrónicos puedo emitir a través de la API de Alanube?

Los más comunes incluyen facturas y notas crédito/débito (y otros, según tu caso de uso y habilitación). Lo importante es que tu sistema conserve el control del flujo y Alanube gestione el procesamiento/validación y la respuesta de estado, conforme con las regulaciones de Colombia.

### ¿Alanube cumple con los requisitos establecidos por la DIAN?

Sí, Alanube cumple con todos los requisitos establecidos por la DIAN (Dirección de Impuestos y Aduanas Nacionales) y garantiza que todas las facturas electrónicas sean válidas y estén en conformidad con las regulaciones fiscales.

### ¿Qué nivel de seguridad ofrecen Alanube para garantizar la protección de los datos?

Alanube utiliza tecnología de encriptación avanzada y cumple con las mejores prácticas de seguridad para proteger los datos sensibles de sus usuarios, asegurando que la información esté segura en todo momento.

### ¿La API de facturación electrónica de Alanube puede manejar grandes volúmenes de facturación?

Sí, la API de Alanube está diseñada para manejar grandes volúmenes de facturación de manera eficiente, con una arquitectura escalable que garantiza un rendimiento óptimo incluso en picos de demanda.

### ¿Qué es un proveedor de facturación electrónica en Colombia y cómo lo valido ante la DIAN?

Un proveedor autorizado por la DIAN es una empresa habilitada para prestar servicios tecnológicos dentro del esquema de facturación electrónica en Colombia. Puedes validar la habilitación en el listado oficial.

Alanube ofrece un modelo BaaS vía API REST para integrar tu sistema y automatizar emisión y estados.

### ¿Cómo funciona la integración de software de facturación electrónica vía API con sistemas contables?

La integración consiste en mapear los datos de tu sistema contable (clientes, impuestos, ítems y totales) al modelo de la API REST y enviar los documentos para su procesamiento dentro del flujo de facturación electrónica en Colombia (DIAN).

### ¿Cuál es la diferencia entre un software de facturación electrónica y una API de facturación para integradores?

Un software (SaaS) es una plataforma lista para usar: facturas desde una interfaz y el proveedor administra el flujo por ti.

Una API de facturación (BaaS) es un motor para integrar: tu ERP/POS/software contable envía los datos por API REST y recibe estados automáticamente dentro del flujo de facturación electrónica en Colombia (DIAN).
Alanube es un modelo API/BaaS pensado para software houses, integradores y resellers.

### ¿Cómo cambiar de proveedor de facturación electrónica?

Debes notificar a la DIAN, hacer las pruebas técnicas e integrarte al nuevo proveedor. Es un proceso sencillo si el proveedor te acompaña.

Con Alanube el cambio es fácil y acompañado paso a paso. [Empieza aquí](https://www.alanube.co/colombia/contacto/#contact-form)

### ¿Es compatible Alanube con otros sistemas?

Sí, Alanube es compatible con diversos sistemas de gestión empresarial (ERP) y plataformas contables, permitiendo una integración sencilla y eficiente.

### ¿Ofrecen soporte técnico para la integración y el uso de la API de Alanube?

Sí, Alanube ofrece soporte técnico dedicado para la integración y el uso de su API, asegurando que la implementación y operatividad sean lo más fluida posible.

### ¿Qué costos están asociados con la facturación electrónica vía API?

Dependen del volumen de facturación, el nivel de integración, almacenamiento y soporte. Muchos proveedores ofrecen paquetes según tus necesidades.
