## Preguntas frecuentes sobre Nitro Factura

01¿Cómo se maneja el soporte técnico de la API?

El soporte opera exclusivamente mediante canales escritos: sistema de tickets y correo electrónico. Este modelo garantiza trazabilidad completa y resolución documentada de cada incidente. Todos los planes incluyen una sesión de onboarding técnico inicial donde acompañamos a tu equipo en la configuración del entorno, autenticación por API Key, primeras emisiones en sandbox y configuración de webhooks.

02¿Qué vigencia tienen los paquetes de documentos?

Todos los paquetes tienen vigencia de un (1) año calendario desde la fecha de activación. Durante ese período puedes consumir los documentos sin restricción mensual. Los documentos no utilizados al vencimiento no son acumulables ni reembolsables.

03¿Qué ocurre si supero el Rate Limit de mi plan?

La API responde con HTTP 429 (Too Many Requests). Las solicitudes rechazadas no consumen documentos del paquete. Si tu operación requiere mayor concurrencia de forma sostenida, el camino recomendado es escalar al siguiente plan. Nuestro equipo comercial puede ayudarte a proyectar el plan adecuado según tu patrón de uso.

04¿Cómo funciona la integración con Cloud Storage externo?

Nitro Factura se integra de forma nativa con AWS S3, Google Cloud Storage, Cloudflare R2 y Backblaze B2. Una vez configurado tu bucket, la plataforma replica automáticamente los XML y PDF de cada documento directamente en tu infraestructura, eliminando la dependencia del almacenamiento interno de Aliaddo y optimizando la latencia de acceso para tus clientes. Esta funcionalidad está disponible en todos los planes.
