### Condiciones Comerciales y Operativas

Información completa sobre el funcionamiento de los paquetes Casa de Software

#### Modelo de Distribución

La Casa de Software tiene **autonomía total** para distribuir
el consumo de documentos entre sus clientes vinculados. Tú decides cuántos
documentos asignas a cada NIT.

#### Vigencia y Consumo

El contrato tiene una vigencia de **un (1) año**. Si se agota
el cupo antes del tiempo, se debe **adquirir un nuevo paquete**
para continuar la operación.

Facturación por anticipado anual

#### Notificaciones Compartidas (6x)

Se asigna un cupo **global** de correos equivalente a
**6 veces el volumen** del paquete. Este cupo es
**compartido** entre todos los clientes de la Casa de Software.

Paquete 50K = **300.000 correos** compartidos

Excedente: **$1.200 COP** por cada 1.000 envíos

#### Requisito de Activación

Se requiere contar con un mínimo de **3 clientes habilitados**
en el API en un plazo máximo de **seis (6) meses** para
mantener la tarifa de distribuidor.

#### Soporte "Dev-to-Dev"

El soporte técnico es especializado y se brinda exclusivamente al
**equipo de desarrollo** de la Casa de Software. MATIAS API
**no ofrece mesa de ayuda a usuarios finales**; dicha
responsabilidad recae sobre el distribuidor.

#### Almacenamiento Adjuntos

Cada paquete incluye una cuota de almacenamiento compartida para adjuntos
en **infraestructura AWS S3**.

Excedente: **$15.000 COP/año** por cada GB adicional

#### Servicio Anual de Firma Digital Integrada

El paquete de documentos **no incluye** certificados de firma digital

##### Suscripción Anual (Custodia)

$104.000 COP/NIT/año

IVA y comisiones de pasarela incluidas

- **Activación Express** en minutos vía validación biométrica
- **Custodia criptográfica** en servidores MATIAS API
- Timbrado automatizado sin intervención manual
- No es exportable/descargable

##### Certificado Exportable (.p12)

Desde $144.000 COP / 2 años

Para uso en plataformas de terceros

- Archivo **.p12 descargable**
- Vigencia de **2 años**
- Adquirir via [Certificate Manager](https://certs.matias-api.com/)
- No aplica suscripción anual

#### Limpieza Diaria (04:00 AM) y Regeneración

Rutina de mantenimiento automático para garantizar la eficiencia del servicio

##### ¿Qué se elimina?

A las **04:00 AM**: PDFs, QR, adjuntos temporales y ZIPs.

##### Regeneración bajo demanda

**Regenera en tiempo real** vía API o Interfaz Web.

##### Excepción de Adjuntos

Adjuntos vía payload **excluidos** de limpieza (AWS S3 persistente).

##### Ciclo de Vida

Archivos regenerados son **temporales** — se eliminan en la siguiente rutina.

Los **XML tributarios** se conservan permanentemente y **nunca** se eliminan.
